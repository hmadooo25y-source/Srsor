# مغامرة الصرصور للحروف

لعبة تعليمية للأطفال (من عمر 5 سنوات) لتعلم الحروف العربية والإنجليزية، مع صرصور يمشي إلى الإجابة الصحيحة ويقرأ الحرف والكلمة بصوت عالٍ.

## المميزات

- حروف عربية (27 حرفاً) وإنجليزية (25 حرفاً)، مع صورة لكل حرف.
- اختيار الصورة الصحيحة من بين ثلاث صور، مع نجوم ورسالة تشجيع.
- صرصور متحرك يقرأ الحروف عند الضغط عليها.
- ثلاثة أوضاع للعب: "صورة ← حرف" و"ما أول حرف؟" و"لعبة الذاكرة".
- تعمل بدون إنترنت بالكامل: ملف واحد لا يحتاج أي مكتبة أو خط خارجي.
- مناسبة للهاتف والحاسوب.
- قابلة للتثبيت على الشاشة الرئيسية كتطبيق (PWA) مع أيقونة وتخزين مؤقت للعمل بدون إنترنت.

## الملفات

- `index.html`: اللعبة كاملة.
- `manifest.webmanifest` و`sw.js` و`icons/`: ملفات PWA للتثبيت والعمل بدون إنترنت.

## التشغيل

افتح الملف `index.html` في أي متصفح حديث. لا يحتاج تثبيت أو خادم.

## ملاحظات

- الصوت يعتمد على خاصية النطق في المتصفح/الجهاز، لذا يختلف حسب الجهاز ولغات الصوت المثبتة. إذا لم يتوفر صوت عربي، تعمل اللعبة بدونه.
- الخطوط المستخدمة خطوط النظام (Tahoma / Arial) لضمان العمل بدون إنترنت.
